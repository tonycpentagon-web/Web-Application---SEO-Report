# Pentagon Insight Flow ? local SEO Team Lead evaluation

This package is for local evaluation. It contains application source, Composer dependencies, the React production build and Node PDF-renderer dependencies. It contains no accounts, passwords, production environments, real client documents, database or uploaded storage. Synthetic fixtures are explicitly labelled.

A ZIP alone is not a running installation. Install/check Windows PHP 8.2+ (the bundled dependencies were verified on PHP 8.4), Python 3.12 x64, Node 22+ and Microsoft Edge. See WINDOWS-REQUIREMENTS.md, then LOCAL-INSTALLATION.md. Runtime installers, Composer executable, Python wheels and Edge are not bundled. New Python setup downloads pinned dependencies and needs internet. No Docker, WSL, remote deployment or administrator shell is required by these scripts.

Extract to a NEW private, writable folder, for example D:\Pentagon-SEO-Test. Keep the folder outside publicly served XAMPP htdocs. Run installation, create your own administrator, then start. The documented default browser address is http://127.0.0.1:8787. Source data and accounts remain local to that copy.

Read TEST-ACCOUNTS-SETUP.md for the evaluation checklist, LOCAL-STOP.md before shutting down and BACKUP-RESTORE.md before updates. Never place real client documents into synthetic reports or publish them automatically. No hosted public URL is supplied by a local installation.
