# User manual

Sign in with your existing account. Credentials were not reset. A Super Admin manages workspace-wide access; Admins see only their authorized clients/projects unless explicitly Super Admin. SEO Managers and SEO Executives work within assigned scope; Client Viewers receive only approved delivery access. Inactive accounts and archived clients remain restricted.

Create/select a client and project, then reporting period. Upload supported source files from the project's Documents screen; check progress, retained attempts and warnings. Originals remain private. Retry a failed extraction only after reviewing its error and correcting the cause. Duplicate observations and source references are retained; do not delete evidence to make charts cleaner.

Use normalized Data Review to inspect source locations, make factual corrections and record explicit review decisions. Human verification is a separate evidence-bound action where required. Add source-backed executive commentary and submit for approval; missing/pending commentary remains visibly labeled. Never approve a record you have not checked or infer exact ranking positions from page groups.

Report Delivery shows publication readiness, validation blockers, commentary/revision state, export history and client sharing controls. Client-style Draft Preview is a private executive-first PDF with Draft watermark. Internal Audit Export includes full source/review metadata. Choose profile, export and wait for completion; inspect failures before an explicit retry. A Draft export does not publish or approve anything. Publication and sharing stay disabled until every existing review and validation requirement passes. Approved publications are versioned; share links have expiry/revocation/download controls. Do not share Hann's current unresolved Draft publicly.

Super Admins can open System Health from navigation, refresh current status and run local Python/Chromium probes. Missing evidence displays Not verified. Retained failed jobs are history, not an invitation to delete or blindly replay them. The page is diagnostic only and does not certify deployment readiness.


In Clients, authorized administrators add a client with its actual name/website and open its project workspace; add a project and assigned team using existing membership controls. In the project's Reporting Periods, create the intended monthly/custom period with accurate dates before uploading. Existing identity/duplicate checks apply; do not create replacement records for the current Hann's client or period.

Open the period's Report Dashboard to view actual normalized KPI cards, channel/device/event/category charts, rankings, SEO activities and AI evidence. Switch sections and inspect source links when a figure needs checking. Provisional labels indicate that approval/source verification is incomplete; absent comparisons or daily series must remain absent. Tables use existing pagination where provided. Dashboard display and private Draft PDF generation do not change record approval or report publication state.
